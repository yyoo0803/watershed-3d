# 지형 유향 도구 (watershed-3d)

브이월드(VWorld) 3D 지형 위에서 유역 경계를 그리면, 경계 내부의 실제 지형 표고를 조회해
D8 방식으로 유향(물 흐름 방향)과 흐름누적(flow accumulation)을 계산해 화살표로 보여주는
로컬 웹앱입니다. 여러 유역을 동시에 그려 비교하고, 결과를 CSV/GeoJSON으로 내보낼 수 있습니다.

이 도구는 Claude 아티팩트가 아닌 **로컬 정적 웹앱**입니다. 아티팩트는 보안 정책상 지도
타일·지형(DEM) 같은 외부 GIS 서비스에 접속할 수 없기 때문입니다.

## 실행 방법

1. `config.js`에 브이월드 API 인증키가 들어있는지 확인합니다.
2. 아래 명령으로 로컬 서버를 띄웁니다.
   ```
   python -m http.server 5173 --directory watershed-3d
   ```
   (Claude Code를 쓰고 있다면 `.claude/launch.json`에 등록된 "watershed-3d" 프리뷰로도 실행할 수 있습니다.)
3. 브라우저에서 `http://localhost:5173` 을 엽니다.

## 인증키 재발급이 필요하면

1. https://data.vworld.kr 에서 회원가입 후 [오픈API > 인증키발급]으로 이동합니다.
2. 인증 도메인에 `localhost` 를 입력합니다 (포트 번호는 넣지 않습니다).
3. 승인까지 다소 시간이 걸릴 수 있습니다. 발급된 키를 `config.js`의 `apiKey`에 넣습니다.
4. 만약 지도가 뜨지 않으면 `config.js`의 `version`을 `"2.0"` ↔ `"3.0"`으로 바꿔가며 시도해 보세요.

## 사용법

1. 좌표를 입력하거나 "내 위치로 이동"을 눌러 원하는 현장으로 이동합니다.
2. "새 유역 그리기 시작"을 누르고 지도를 클릭해 경계점을 3개 이상 찍습니다.
3. "그리기 완료"를 누르면 경계가 확정되고, 자동으로 유향·흐름누적이 계산되어 화살표로 표시됩니다.
4. 이 과정을 반복해 여러 유역을 동시에 그릴 수 있습니다. 각 유역은 서로 다른 색으로 구분되고,
   좌측 "유역 목록"에서 점 개수·면적(ha)·싱크 개수·최대 흐름누적을 한눈에 비교할 수 있습니다.
5. 목록의 × 버튼으로 유역 하나만 지우거나, "전체 삭제"로 전부 지울 수 있습니다.
6. 격자 해상도 슬라이더를 바꾼 뒤 "전체 다시 계산"을 누르면 그려둔 모든 유역을 새 해상도로
   다시 계산합니다 (다시 그릴 필요 없음).
7. "CSV"/"GeoJSON" 버튼으로 그려둔 모든 유역의 격자점(위경도·표고·유향·경사·흐름누적)과
   경계 폴리곤을 파일로 내려받을 수 있습니다.

### 경계 그리기·수정 조작법

그리거나 수정하는 동안 지도 위쪽에 안내 막대가 뜹니다.

- **지도 클릭**: 점 추가 (그리기 중일 때)
- **흰 점 드래그**: 점 위치 이동 — 드래그하는 동안 지도는 움직이지 않습니다
- **변 가운데 작은 점 드래그**: 그 자리에 새 점을 끼워 넣으면서 이동
- **흰 점 우클릭**: 그 점 삭제 (또는 점을 클릭해 노랗게 선택한 뒤 "선택 점 삭제")
- **빈 곳 우클릭 / Backspace / Ctrl+Z**: 마지막 점 취소 (그리기 중일 때)
- **Enter 또는 더블클릭**: 완료 · **Esc**: 취소
- 지도 이동은 평소처럼 빈 곳을 드래그하면 됩니다 (점이 찍히지 않습니다)

유역 목록의 각 항목에는 버튼이 있습니다.

- **유역 이름 클릭**: 그 유역으로 지도 이동
- **수정**: 완성된 유역의 경계 점을 드래그·추가·삭제해 다듬고, 완료하면 즉시 다시 계산
- **복제**: 그 경계를 그대로 복사해 새 유역을 시작 — 예: "개발 전" 유역을 복제해서 조금 고친 뒤
  구분을 "개발 후"로 두고 완료하면 개발 전·후 비교용 유역이 바로 만들어집니다

### 화살표 색·굵기 읽는 법

- 가늘고 옅은 청록~주황 화살표: 개별 셀의 경사에 따른 방향 (주황일수록 급경사)
- 굵고 진한 파란 화살표: 흐름누적이 높은 지점 — 여러 상류 셀의 물이 모여 지나가는,
  실제 하도(개울)가 형성될 가능성이 높은 경로로 추정되는 지점
- 빨간 점: 싱크(내리막이 없어 물이 고이는 지점)

## 위치 찾기

- **지번·도로명 주소 검색**: "위치 찾기" 안의 검색창에 한글 지번(예: "서울특별시 종로구
  세종로 1") 또는 도로명 주소를 입력하면 브이월드 검색 API로 후보를 찾아 목록으로
  보여줍니다. 클릭하면 그 위치로 이동합니다. 지번 검색 결과가 없으면 자동으로 도로명
  주소로 재검색합니다.
- **실시간 위치 추적**: "실시간 위치 추적 시작"을 누르면 브라우저의 위치 권한을 요청하고,
  이후 위치가 갱신될 때마다 지도 위 파란 점이 따라 움직입니다. "지도가 내 위치 따라가기"를
  켜 두면 내비게이션처럼 지도도 함께 따라옵니다. 상태창에 위치 정확도(±m)가 표시됩니다.
- **PC에서의 한계**: GPS가 없는 PC는 와이파이·인터넷 주소로 위치를 추정하므로 오차가
  수백 m~수 km이거나 아예 실패할 수 있습니다(Windows 위치 서비스가 꺼져 있으면 실패).
  내비게이션 수준의 정확한 위치는 GPS가 있는 휴대폰에서 열어야 하며, 휴대폰은 보안
  정책상 **HTTPS 주소**로 접속해야만 위치 기능이 켜집니다 — 지금의 `localhost` 실행
  방식으로는 이 PC에서만 열리므로, 현장 휴대폰용으로 쓰려면 별도의 HTTPS 배포가 필요합니다.

## 개발 전/후 구분

"새로 그릴 유역 구분" 드롭다운에서 일반/개발 전/개발 후를 선택한 뒤 유역을 그리면, 유역
목록에 해당 태그가 표시되고 CSV·GeoJSON 내보내기에도 `category` 값으로 포함됩니다.
개발 전·후 유역을 각각 그려서 흐름누적·면적 등을 나란히 비교하는 용도로 씁니다.

## 메모

유역 목록의 각 항목에는 작은 메모 입력란이 있습니다. 여기 적은 내용은 CSV의 `memo`
컬럼과 GeoJSON 경계 폴리곤의 `memo` 속성에 그대로 포함되어 저장됩니다.

## DXF 불러오기

"DXF 불러오기" 섹션에서 CAD로 작성한 DXF 파일(LINE, LWPOLYLINE/POLYLINE, 일부 HATCH
해치 지원)을 업로드하면, 도형을 인식해 지도 위에 배치할 준비를 합니다.

1. "DXF 파일 선택"으로 파일을 올리면 인식된 도형 개수가 표시되고, DXF 좌표계의 두
   기준점(자동으로 도형 전체의 좌측하단·우측상단 모서리가 채워짐 — 다른 두 점을
   쓰고 싶으면 숫자를 직접 수정)이 미리 채워집니다.
2. 각 기준점 옆의 "지도 클릭" 버튼을 누른 뒤, 그 DXF 좌표가 실제로 위치할 지도 위
   지점을 클릭합니다. 두 기준점이 모두 지정되면 DXF 도형 전체(축척·회전 포함)가
   자동으로 지도 위에 배치되어 반투명 흰색 선/도형(해치는 옅은 노란색)으로 표시됩니다.
3. "불러온 도형" 목록에서 원하는 도형에 "유역으로"를 누르면 그 도형을 그대로 새
   유역으로 만들어 즉시 유향·흐름누적을 계산합니다. "다듬기"를 누르면 그 도형의 점들로
   그리기 모드가 시작되어, 위 조작법대로 점을 드래그·추가·삭제해 수정한 뒤 완료할 수
   있습니다.

DXF는 CAD 도면 자체의 좌표계(측량 좌표계, 로컬 좌표 등 무엇이든)를 그대로 쓰되, 두
기준점의 실제 지도 위치만 알려주면 되는 방식이라 파일이 어떤 좌표계를 쓰는지 몰라도
됩니다. 기준점 두 개를 서로 멀리 떨어진 지점으로 고를수록 배치 정확도가 좋아집니다.

## 한계

- 유향·흐름누적 계산은 D8(8방향 최급경사) 기반 격자 알고리즘입니다. 지형학적 보정
  (flat 지역 처리, depression filling), 하도추적, 유출량 산정 등은 포함하지 않으며
  실제 유역분석 소프트웨어(ArcHydro, TauDEM, HEC-HMS 등)를 대체하지 않습니다.
- 브이월드는 국내(대한민국) 지형·영상 위주로 커버리지가 제공됩니다.
- 격자 해상도는 성능을 위해 유역당 최대 20×20으로 제한됩니다.
- 면적(ha)은 등장방형(equirectangular) 근사로 계산합니다. 이 도구가 다루는 작은
  (수 ha~수십 ha급) 유역 범위에서는 오차가 무시할 만한 수준입니다.
- DXF의 LINE·LWPOLYLINE·POLYLINE 파싱은 실제 파일로 검증했지만, HATCH(해치) 경계
  추출은 DXF 스펙이 복잡해 일부 파일에서 인식되지 않을 수 있습니다(경계선 자체는
  LWPOLYLINE으로도 같이 그려져 있는 경우가 많아 그쪽을 "유역으로" 가져오면 됩니다).
  도형이 아주 많은(수천 점 이상) DXF는 기준점 지정 후 배치가 느려질 수 있습니다.
- 기본 지도(GRAPHIC)는 실제로 위성/항공사진입니다. 브라우저 탭이 화면에 보이지 않는
  상태에서는 렌더링이 멈춰 지도가 단색으로 굳어 보일 수 있는데, 실제 사용 중(탭이
  화면에 떠 있을 때)에는 발생하지 않습니다 — 만약 지도가 멈춘 것처럼 보이면 탭을
  다시 활성화하거나 새로고침하세요.
